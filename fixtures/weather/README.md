# Recorded weather data

`archive-api.open-meteo.com/v1/archive-db9205666f7acb0c` is the [Open-Meteo historical weather API](https://open-meteo.com/en/docs/historical-weather-api) response for the synthetic route in `../gpx/snowdon.gpx`: hourly values for 14 June 2025 (UTC) at one point in the middle of the route, downscaled to the route's mean height of 830m, recorded on 2026-11-10. `archive-api.open-meteo.com/v1/archive-845f6c2effc8cda6` is the daily low, high and snowfall at the same point for the fortnight before (31 May to 13 June 2025), recorded on the same day. The directory layout mirrors the request URL, and the file name ends in a hash of the query string, so tests can serve it with `RecordedFetcher`. If a request changes, its hash changes too: the failing test names the file it expected, and the response has to be recorded again. The responses are stored as received.
